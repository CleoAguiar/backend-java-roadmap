This repository documents my journey in **Java Backend Development**, combining structured learning with practical projects of increasing complexity.

The goal is to build a professional backend portfolio while practicing software engineering concepts, development workflows, testing, security, databases, containerization, and CI/CD.

The projects are based on the recommendations from [roadmap.sh](https://roadmap.sh/backend).

## 🗺️ Roadmap

The portfolio is organized into three projects with increasing levels of complexity.

### 1. Beginner — Todo List API ✅

A RESTful API that allows authenticated users to manage their own tas

**Implemented:**

- CRUD operations
- RESTful API design
- Authentication and authorization with JWT
- User resource isolation
- Data validation and global error handling
- Pagination
- PostgreSQL persistence
- Unit and integration testing
- OpenAPI / Swagger documentation
- Docker containerization
- Continuous integration with GitHub Actions
- Versioning and release management

**Release:** `v1.0.0`

### 2. Intermediate — [URL Shortening Service](https://roadmap.sh/projects/url-shortening-service) 🚧

Build a service that generates short URLs, redirects users to the original addresses, and tracks access statistics.

**Main topics:**

- Unique short-code generation
- HTTP redirects
- Database indexing
- Caching with Redis
- Rate limiting
- Concurrency and data consistency
- Performance testing
- Containerized deployment

### 3. Advanced — [Scalable E-Commerce Platform](https://roadmap.sh/projects/scalable-ecommerce-platform) ⏳

Build an e-commerce platform using microservices that can be developed, deployed, and scaled independently.

**Main topics:**

- Microservices architecture
- Product catalog, inventory, cart, order, payment, and user services
- Synchronous and asynchronous communication
- API Gateway and service discovery
- Event-driven architecture
- Resilience and distributed transactions
- Centralized logging, metrics, and tracing
- Docker Compose and Kubernetes
- CI/CD and cloud deployment
